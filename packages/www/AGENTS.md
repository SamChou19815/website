# www (dev-sam-website)

Two distinct purposes under a single TanStack Start project (Vite, file routes in
`src/routes`, every page prerendered to static HTML in `dist/client`)

## The Portfolio Website + Blog

- Most of the code in `../../crates/sam-web`
- Should have a TUI feel
- Things should be keyboard navigable
- Styled using tailwind

## Personal Tools

- Using supabase as backend
- Free-form design, but should stick to existing style
- Styled using tailwind
